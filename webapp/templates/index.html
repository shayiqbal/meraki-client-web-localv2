Step 1 — Select Network

Choose the network whose devices you want to re-address. All network types are listed — appliances, access points, switches and cameras.

Step 2 — Select Devices in

Tick the devices that should receive the new address. Use Select All to take the whole network, then untick any device you want to leave alone.

Step 3 — New Address & Preview

Enter the site address to apply to every selected device. Meraki geocodes the address and moves each device's dashboard map marker to match. No other device setting is changed.

Step 4 — Results

Each device is updated independently — a failure on one device does not stop the rest. Every update is verified by re-reading the device from Meraki.
